# blog-immagini-temp

Cartella di passaggio **temporanea** per le immagini del blog di [Tessiland](https://www.tessiland.com).

Il modulo che pubblica gli articoli del blog accetta le immagini solo da un indirizzo web: le immagini vengono caricate qui in `img/`, il sito le copia, e subito dopo vengono cancellate.

- Contiene **solo** immagini destinate alla pubblicazione sul blog (copertine, miniature, immagini degli articoli). Nient'altro.
- Rete di sicurezza: un'automazione notturna cancella ogni immagine rimasta qui da più di 48 ore.
